# CodeLume-Skill Privacy Policy

Effective date: October 10, 2026

CodeLume-Skill is a Skills-only plugin that provides instructions and reference
material for studying source code. It does not operate a server, create user
accounts, use analytics, or provide its own storage or authentication system.

## Data handled by the plugin

The plugin itself does not collect, retain, sell, or share personal data. The
publisher does not receive repository contents, prompts, generated learning
guides, credentials, or usage information through CodeLume-Skill.

When the plugin is used in ChatGPT, Codex, or another compatible host, the host
may process prompts, repository files, tool results, and generated output to
perform the requested task. That processing is governed by the host's own
privacy policy, account settings, retention rules, and administrative controls.

## User responsibilities

Only provide source code and other material that you are authorized to process.
Review files before sharing them with a host, and remove secrets, credentials,
personal information, and confidential material that is not required for the
task.

## Third-party links

The plugin documentation may link to source repositories and other third-party
pages. Those services operate under their own privacy policies.

## Changes and contact

Material changes to this policy will be published in this repository. Questions
or privacy requests can be submitted through the public support page:

https://github.com/JiangHN010/CodeLume-Skill/issues
